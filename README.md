# Папки и репозитории GitHub

Приложение сравнивает имена папок первого уровня с именами публичных репозиториев указанного аккаунта GitHub. Регистр букв при сравнении игнорируется.

1. Выберите локальную папку.
2. Введите логин GitHub и нажмите «Сравнить».
3. Зелёные строки показывают совпадения, серые — репозитории только на GitHub, красные — папки без совпадения среди публичных репозиториев.

Двойной щелчок по ссылке открывает репозиторий в браузере. Для сравнения нужен интернет. Вход в GitHub не требуется.

## Запуск

Запустите из папки проекта с помощью Python 3 с Tkinter.

```powershell
python app.py
```

`app.py` запускает приложение, `gui.py` отвечает за окно, а `comparison.py` загружает репозитории и сравнивает их с папками.

## Сборка для Windows x64

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Zip
```

Скрипт создаёт окружение и устанавливает PyInstaller. Готовый файл находится в `dist\GitHubFolderComparison\GitHubFolderComparison.exe`. Для переноса приложения скопируйте всю папку `GitHubFolderComparison` или используйте готовый ZIP из `dist`. Параметр `-Zip` можно опустить.
